# Smile Care Studio

Crie uma landing page profissional e sofisticada para uma odontopediatra chamada Dra. Ana Carolina.

IMPORTANTE:
Esta é uma DEMONSTRAÇÃO COMERCIAL para apresentar à profissional. Não invente CRM, endereço, telefone, formação, certificações, depoimentos, prêmios ou qualquer outra informação pessoal que não tenha sido fornecida. Quando uma informação específica não estiver disponível, não crie dados fictícios. Use textos institucionais genéricos e deixe espaços preparados para posteriormente inserir as informações reais.

OBJETIVO:
Criar uma página que transmita confiança, acolhimento, profissionalismo e especialização em atendimento odontológico infantil, levando principalmente os pais/responsáveis a entrarem em contato pelo WhatsApp.

IDENTIDADE:
- Nome: Dra. Ana Carolina
- Especialidade: Odontopediatria
- Público: bebês, crianças, adolescentes e pacientes especiais
- Serviços/áreas mencionadas no perfil:
  • Odontopediatria
  • Pré-natal odontológico
  • Atendimento de pacientes especiais
  • Atendimento com sedação
- Instagram: @adentistacarolina
- CTA principal: Agendar consulta pelo WhatsApp

ESTRUTURA DA PÁGINA:

1. HERO
Criar uma primeira seção visualmente impactante.

Título sugerido:
"Um cuidado especial para cada fase do sorriso"

Subtítulo:
"Odontopediatria com acolhimento, segurança e atenção às necessidades de cada criança."

Botão principal:
"Agendar pelo WhatsApp"

Botão secundário:
"Conheça o atendimento"

Ao lado do texto, criar espaço para uma foto profissional da Dra. Ana Carolina. Não inventar uma foto. Se não houver imagem disponível, utilizar um placeholder elegante que possa ser substituído posteriormente.

2. APRESENTAÇÃO DA DOUTORA
Criar uma seção com:
"Conheça a Dra. Ana Carolina"

Texto provisório:
"Um atendimento pensado para tornar a experiência odontológica mais tranquila, acolhedora e segura para crianças, adolescentes e suas famílias."

Deixar a estrutura preparada para adicionar posteriormente:
- biografia real
- formação
- especializações
- registro profissional
- foto profissional

Não inventar essas informações.

3. ESPECIALIDADES / ATENDIMENTOS
Criar cards elegantes para:

"Odontopediatria"
"Pré-natal odontológico"
"Atendimento de pacientes especiais"
"Atendimento com sedação"

Cada card deve ter uma descrição curta, profissional e acolhedora.

4. SEÇÃO PARA PAIS
Criar uma seção com o conceito:
"Mais tranquilidade para os pais. Mais confiança para as crianças."

Texto:
"Cada criança possui necessidades e características diferentes. Por isso, o atendimento deve respeitar seu tempo, sua individualidade e proporcionar uma experiência positiva desde os primeiros contatos com o dentista."

5. EXPERIÊNCIA / DIFERENCIAIS
Criar uma seção visual destacando conceitos como:
- Atendimento individualizado
- Ambiente acolhedor
- Atenção às necessidades de cada criança
- Cuidado com pacientes especiais
- Orientação para pais e responsáveis

Não apresentar esses itens como certificações ou fatos profissionais específicos; eles devem funcionar como posicionamento institucional da página.

6. FAQ
Criar perguntas frequentes relacionadas à odontopediatria, por exemplo:
- Quando meu filho deve ir ao odontopediatra?
- Como funciona a primeira consulta?
- O atendimento é indicado para bebês?
- Como funciona o atendimento de pacientes especiais?
- Quando a sedação pode ser utilizada?

As respostas devem ser informativas e gerais, sem fazer promessas médicas específicas.

7. CTA FINAL
Criar uma seção forte:

"Vamos cuidar do sorriso do seu filho?"

Texto:
"Entre em contato para conhecer o atendimento e tirar suas dúvidas."

Botão:
"Agendar pelo WhatsApp"

8. FOOTER
Exibir:
Dra. Ana Carolina
Odontopediatria
Instagram: @adentistacarolina
Botão/link para WhatsApp

Não inventar número de telefone, endereço ou informações de registro.

DESIGN:

Quero um visual premium de clínica odontológica infantil, mas sem parecer infantil demais.

Evitar:
- excesso de rosa
- estética de desenho animado
- aparência de site genérico de dentista
- excesso de elementos
- visual muito colorido

Priorizar:
- branco
- tons claros e suaves
- detalhes sofisticados
- bastante espaço em branco
- tipografia moderna
- fotos com aparência natural
- cantos levemente arredondados
- microanimações discretas
- excelente hierarquia visual

O site precisa transmitir:
ACOLHIMENTO + CONFIANÇA + PROFISSIONALISMO + ESPECIALIZAÇÃO.

RESPONSIVIDADE:
O site será apresentado principalmente pelo celular, então faça a versão mobile excepcionalmente bem. O botão de WhatsApp deve permanecer muito fácil de encontrar.

IMPORTANTE PARA ESTA DEMONSTRAÇÃO:
Não quero um site cheio de informações inventadas. Quero uma estrutura visual extremamente profissional que possa posteriormente receber as informações reais da Dra. Ana Carolina.

Crie o site completo e funcional, com navegação suave entre as seções e CTA de WhatsApp preparado para receber posteriormente o número correto.
